# Lyrrie

Minimal support and privacy website for Lyrrie on iPhone.

Live site: https://maxpoi.github.io/Lyrrie/

## Files

- `index.html` — support page
- `privacy/index.html` — privacy policy
- `styles.css` — shared design
- `script.js` — copy-email interaction
- `assets/` — Lyrrie app icon and social preview

The site is plain HTML, CSS, and JavaScript with no build step or dependencies.
